### Previous projects

**[Flotilo](https://flotilo.pl)** — Heavy equipment auction platform

An online auction platform specializing in heavy equipment, including forestry machinery, agricultural equipment and construction machinery.

Built with Dart, Flutter and Firebase, featuring a serverless architecture powered by Firestore and Cloud Functions, CRM and third-party sales platform integrations, and automated email communication. The project also included a mobile application previously published on Google Play.

**[JakiPIT](https://jakipit.pl)** — Tax comparison calculator

A web-based calculator helping users compare taxation options in Poland. Developed using .NET and Blazor, evaluating both Blazor Server and Blazor WebAssembly before adopting the client-side approach to improve interaction responsiveness and perform calculations locally.
